# Bikcraft - Bicicletas Elétricas

Projeto desenvolvido durante o curso de **HTML e CSS da [Origamid](https://www.origamid.com/)**, com o objetivo de praticar e aprofundar os conhecimentos em desenvolvimento front-end.

O projeto consiste em um site institucional fictício de uma empresa de bicicletas elétricas personalizadas, com páginas de apresentação dos produtos, seguros, contato e orçamento.

## Tecnologias utilizadas

- HTML5
- CSS3

## O que foi praticado

Durante o desenvolvimento, foram trabalhados conceitos como:

- Estruturação de páginas com HTML semântico.
- Estilização e organização de layouts com CSS.
- Flexbox e CSS Grid.
- Responsividade e Media Queries.
- Organização e reutilização de classes CSS.
- Formulários e elementos de navegação.
- Tipografia, cores e componentes reutilizáveis.

## Páginas do projeto

- **Início:** apresentação da Bikcraft e seus diferenciais.
- **Bicicletas:** apresentação dos modelos disponíveis.
- **Seguros:** planos e vantagens oferecidas.
- **Contato:** informações e formulário de contato.
- **Orçamento:** formulário para solicitação de orçamento.
- **Termos e Condições:** informações sobre os serviços.

## Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/mylenaes/bikcraft-html-css.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd bikcraft-html-css
   ```

3. Abra o arquivo `index.html` no navegador.
